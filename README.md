# Frog Pond Game

Логическая игра про лягушек на лилиях.

## О проекте

Этот проект — полностью переработанная версия оригинальной игры. 
Изначально проект был создан с использованием TanStack Start (SSR), но для упрощения деплоя и избавления от лишней магии был перенесен на чистый **Vite + React**.

- Для UI использовался Lovable
- Для логики Cursor
- Рефакторинг и мелкие изменения Junie

### Что изменилось:
- Удален TanStack Start и TanStack Router.
- Настроен стандартный Vite для клиентского приложения.
- Сохранена вся игровая логика, компоненты и ассеты.
- Используется Tailwind CSS v4.
- Стек: React 19, Framer Motion, Radix UI, Lucide.

## Разработка

Проект использует `bun` в качестве менеджера пакетов.

### Установка зависимостей
```bash
bun install
```

### Запуск в режиме разработки
```bash
bun run dev
```

### Сборка
```bash
bun run build
```

Результат сборки будет в папке `dist`.
